# README.md

This repo serves as a log for my journey through getting certified in C# with [freeCodeCamp's Free Foundational C# with Microsoft Certification](https://www.freecodecamp.org/learn/foundational-c-sharp-with-microsoft/) and [Microsoft's Tour of C#](https://learn.microsoft.com/en-us/dotnet/csharp/tour-of-csharp/tutorials/).
